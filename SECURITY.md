# Güvenlik Politikası

## Güvenlik açığı bildirme

Lütfen güvenlik açığı ayrıntılarını public issue, discussion veya pull request içinde paylaşmayın.

Bu repository için GitHub **Security Advisories / Private Vulnerability Reporting** arayüzü kullanılabiliyorsa bildirimi oradan özel olarak gönderin. Bu arayüz kullanılamıyorsa repository sahibine GitHub üzerinden özel ve doğrulanabilir bir iletişim kanalıyla ulaşın.

## Güvenlik kuralları

- Parola, API anahtarı, token, private key, keystore veya üretim kimlik bilgilerini issue/PR içine koymayın.
- Güvenlik açığının yeniden üretimi için gereken en az bilgiyi paylaşın.
- Düzeltme doğrulanmadan exploitable ayrıntıları public olarak yayımlamayın.
