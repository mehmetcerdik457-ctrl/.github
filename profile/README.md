# Mehmet AI Engineering

This GitHub account is organized as an engineering control plane for AI, Android, automation, security, CI/CD, reproducible builds, and release evidence.

Core principles:

- private-by-default for sensitive AI and owner-control code;
- pull-request based changes to protected branches;
- least-privilege credentials and short-lived authentication where possible;
- pinned and reviewed supply-chain dependencies;
- reproducible verification before release;
- no secrets or production signing material in source control.
